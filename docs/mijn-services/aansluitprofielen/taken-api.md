# Aansluitprofiel Taken API

:::info[Werkversie]

Dit aansluitprofiel is een placeholder. Het profiel beschrijft straks hoe
MijnServices kan aansluiten op de Taken API als bron voor taken in de
InteractieServices API.

:::

De Taken API kan worden gebruikt als bron voor taken die in MijnServices worden
getoond of afgehandeld. De uitwerking moet nog beschrijven welke operaties,
gegevens en interpretatieregels nodig zijn om DTO's van de InteractieServices
API te vullen.

Bron:
[OpenVTB Taken API](https://raw.githubusercontent.com/maykinmedia/open-vtb/6ad36eebffa268082f77343d098de32326c0cada/src/openvtb/components/taken/openapi.yaml).
